# 2.0 交付与验证记录

整理日期：2026-10-24（Asia/Shanghai）；本机完整验证于 2026-10-22 完成。当前产品是本地、无登录、多模型软件工作群。此前 1.0 的实现记录存于 [历史交付记录](legacy/DELIVERY-v1.md)，不与当前产品能力混用。

## 当前已实现

- 无登录的本机 Web 工作台：群聊主页、项目切换、任务面板、成员管理、能力中心、18 章学习手册。
- 自带模型接口：兼容 Chat Completions 工具调用，界面系统凭据存储或 .env 引用，项目成员范围，职责/档位/单价/工具配置。
- 手动任务、唯一 @ 成员、按档位和输入单价自动路由、模型规划与人工采用；计划一次事务创建草稿。
- 最多 3 个不同成员任务并发，同成员串行；依赖完成后运行，报告与实际文件变更交接。
- 项目共同说明、近期群消息、依赖报告、文件目录与按需读取；有界上下文与原始事件留存。
- 独立 base/work 副本、读写/检索/精确编辑、变更展示、完成清单校验、冲突拒绝和可重复合入。
- 本次工具确认、拒绝、取消、超时；真实命令、静态页面浏览器交互与截图。
- SKILL.md 导入和资源按需读取；官方 MCP SDK 的 stdio / Streamable HTTP；Workbench 声明式工具插件。
- SQLite 状态/事件/账单，预算事务预留和用量结算，SSE 断线回读，重启标记中断，保留部分文件继续或重新执行。
- Windows / POSIX 启动、浏览器安装脚本、Docker/Compose 配置、依赖锁、CI 矩阵、源码与开源参考说明。

## 待用户配置与未验证部分

- 真实模型凭据由用户在本地配置。尚未完成 GPT/Qwen/DeepSeek 等真实供应商实连、真实需求成功率或费用对比评测。
- 本机 Docker 引擎未运行；仅确认 Compose 配置和 Python 包构建，未宣称镜像构建、容器运行或云部署通过。
- 系统凭据使用 keyring，测试用内存夹具避免写入用户凭据；没有使用真实 API Key 验证每个操作系统的凭据后端。

## 明确的实现边界

- 单用户本机、单服务进程。没有远程账号、多租户或分布式任务领取。
- 文件副本不是 OS 沙箱。获准的命令、插件和 MCP 具有其实际进程/服务权限；文件合入不是抗断电的多文件事务。
- 内置浏览器检查与预览针对静态页面；没有通用桌面 Agent 或常驻开发服务器管理器。
- 自动路由是用户配置的档位与价格规则，不是模型能力排行榜；未测量节省 Token 的比例。
- Token 预留采用保守字节估算，供应商结算有实际差异；金额未含缓存折扣和外部工具费用。
- MCP 每次调用新建会话，支持工具发现和调用，不包含 OAuth、资源订阅、远端长任务或所有服务器特有能力。
- 插件是本项目的清单协议；技能支持元数据、正文和资源读取，不代表所有框架插件/技能脚本无需适配。
- 界面“已完成”表示执行者提交报告；是否达到需求仍需核对测试日志、产物与验收条件。
