# 当前产品定义：本地多模型工作群

用户是一人公司的负责人。一个项目对应一个工作群，负责人将软件项目拆给合适的模型成员，也可以由模型先生成可审查计划。成果必须是文件、命令验证、运行说明和交接报告，而不只是聊天回答。

已实现范围以 README 和 DELIVERY 为准：本地无登录、模型成员、自带凭据、项目成员范围、任务依赖、工作副本、预算、Skills、MCP、声明式工具插件、教程。

评价维度：任务是否完成验收、产物是否可检查、返工次数、总用量、失败是否可恢复。未做真实业务评测前不声称省钱比例、模型排行榜或通用自主交付成功率。

暂未实现：在线插件市场、自动购买接口、云端团队账号、集群调度、OS 级沙箱、无监督发布部署、通用桌面操作、持续运行任意开发服务器的管理器。它们是可评估的后续方向，不是隐藏的已完成能力。
