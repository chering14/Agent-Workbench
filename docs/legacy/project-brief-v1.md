# 1.0 系统说明

业务是企业知识与工单协作。员工查询资料，系统提供引用，依据不足时说明限制，需要人工时准备待确认草稿。确认后创建本地工单，管理员处理状态。

员工访问本租户获准资料、自己的会话与工单。管理员管理本租户知识版本、工单状态与审计。学习者直接在内置教程理解全部核心模块。

## 数据流

登录 -> 会话 -> 保存运行 -> Agent 工具循环 -> 权限过滤检索 -> 引用校验 -> 独立审核 -> 保存结果 -> SSE 展示。

工单：明确意图 -> 草稿 -> 用户确认 -> 事务与唯一约束 -> 正式工单 -> 管理员处理。

## 证据与限制

测试覆盖身份、CSRF、越权、引用、无答案、工单幂等、资料版本、重启、模型协议异常与预算。另有 20 项完整流程合成验收。[交付记录](DELIVERY.md)列出实际结果。

规则演示不调用模型。真实模式已实现接口与工具循环，凭据由用户随后配置，真实供应商与业务效果未验证。

部署是单进程 FastAPI 和 SQLite，检索为词法 BM25，推送为阶段 SSE，工单位于本地数据库。重启后中断任务标记失败，已完成业务状态保留。

工程约束、合成验收、真实模型、实际业务和规模验证分开报告。
