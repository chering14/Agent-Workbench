### 本地验证结果

环境为 Windows，分别使用 Python 3.11.9 与 Python 3.12.10。

| 检查 | Python 3.11.9 | Python 3.12.10 |
| --- | --- | --- |
| `python -m unittest discover -s tests -v` | 13 / 13 通过 | 13 / 13 通过 |
| `python -m agent_workbench eval` | 10 / 10 合成用例通过 | 10 / 10 合成用例通过 |

在本机执行 3.12 时使用 `py -3.12` 替代 `python`。
GitHub Actions 仅写入配置，尚未在远程运行；Linux 尚未验证。
没有模型调用，没有模型费用；上述通过率不能解释为真实业务准确率。

初次测试发现正文通用词“失败”造成无关资料召回，已采用标题加权修正并重新验证。
评测采用精确引用集合比较，能够发现无关的额外引用。

### 已知边界

- 词法相关性不能证明答案充分性。例如 `VPN 月费` 能找到 VPN 资料，但资料未提供费用。
- 引用原文验证不能代替语义核验；当前没有模型生成或判定。
- 本地角色/租户参数不构成身份认证。
- 尚无资料导入、真实工具、工单、持久化、服务端、界面和部署。
