# ADR 0002：完整应用与成品教程

- 日期：2026-10-21
- 状态：采用
- 背景：用户要求先交付完整项目和覆盖全项目教程，随后做功能调整。模型凭据由用户本地配置。

## 决策

交付企业知识与工单协作应用，包括 Web、API、身份、知识版本、检索、真实模型适配、支持和审核角色、人工确认、幂等工单、运行、测试和部署配置。
规则演示显式标注，并共享真实模式的权限与工具执行边界。教程随包提供，内置学习中心直接读取。

## 取舍

1. 直接实现受限工具循环，便于学习；审核可关闭，支持对照实验。
2. SQLite 与单进程后台任务便于复现，多副本前需任务租约和服务端数据库。
3. 使用可解释 BM25，不把规则称为语义 embedding。
4. SSE 推送阶段，最终文本在审核后发布。
5. 本地工单构成业务闭环，外部平台为适配扩展。
6. 协议 Mock 不替代真实供应商与模型质量验证。

交付分别记录测试、浏览器、锁文件、容器配置、镜像构建、模型与规模的实际证据。
